## 🛠️ 기술 스택

이 웹사이트는 다음 기술로 만들어졌습니다.

- **Framework**: [Next.js](https://nextjs.org) 16 (App Router)
- **Library**: [React](https://react.dev) 19
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **Styling**: [Tailwind CSS](https://tailwindcss.com) 4
- **Animation**: [Motion](https://motion.dev) (Framer Motion)
- **Icons**: [react-icons](https://react-icons.github.io/react-icons)

## 📁 프로젝트 구조

```
src/
├── app/                      # Next.js App Router 진입점 (layout, page, 전역 스타일)
├── components/
│   ├── layout/                # 공통 레이아웃 컴포넌트 (Nav 등)
│   ├── sections/               # 페이지를 구성하는 섹션 단위 컴포넌트
│   │   ├── Hi.tsx               # 인트로
│   │   ├── About.tsx            # 소개
│   │   ├── Career.tsx           # 경력
│   │   ├── Projects.tsx         # 프로젝트 목록
│   │   ├── Skills.tsx           # 기술 스택
│   │   └── Contact.tsx          # 연락처
│   └── ui/                     # 재사용 가능한 UI 컴포넌트 (Badge, Card, RichText 등)
├── data/                      # 콘텐츠 데이터 (profile, career, projects, skillGroups 등)
└── lib/                       # 유틸 함수 (scroll 등)
```
